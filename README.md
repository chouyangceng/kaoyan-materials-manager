# 考研电子资料管理系统

这是整个资料库的入口。核心原则：**先收集、再归类；按需整理、定期复盘；任何重要资料都能被搜索到。**

## 快速使用

1. 新下载、截图或收到的资料先放入 `00_收件箱`。
2. 每天学习结束后，用 5 分钟把资料移动到对应科目文件夹。
3. 按《命名规范》重命名，并在 `资料索引.csv` 登记重要资料。
4. 每周更新 `学习进度.md`，并复制一份周复盘模板填写。
5. 过时但不想删除的资料移动到 `99_归档`。

## 跨设备使用

建议将整个文件夹放进 OneDrive、Google Drive、Dropbox 等同时支持 Android 和 Windows 的同步目录。Windows 保留完整本地副本，安卓主要用于查看、扫描和把新资料放入 `00_收件箱`。详细设置见 [同步指南.md](./同步指南.md)。

## 目录说明

| 目录 | 用途 |
|---|---|
| `00_收件箱` | 暂存尚未整理的文件，每周至少清空一次 |
| `01_公共资料` | 考研规划、课程信息和学习方法 |
| `02_政治` | 政治教材、真题、背诵及错题总结 |
| `03_英语` | 单词、长难句、阅读、翻译、作文和真题 |
| `04_数学` | 数学讲义、公式、真题、模拟题及错题总结 |
| `05_专业课` | 专业课资料；可按报考院校和科目继续细分 |
| `06_复习输出` | 周/月复盘、阶段总结和模拟考试记录 |
| `99_归档` | 已结束、重复或暂时不用的资料 |
