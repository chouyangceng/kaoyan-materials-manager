# 安卓端使用说明

这是一个可独立使用的轻量版工具：资料清单、科目分类、收件箱状态、学习进度、复盘记录和更新日志都保存在安卓本机，不依赖 Windows。

## 使用

用安卓浏览器打开 `index.html`，再通过浏览器菜单选择“添加到主屏幕”，即可像 App 一样使用。第一次使用建议先添加一条测试资料。

## 同步

点击“一键同步”会生成 `考研资料管家同步包.json`。把它发送到 Windows 或云盘即可保留备份。资料条目里可以记录 Word、PPT、PDF、图片等附件元数据，也可以修改层级与标签，还能用目录树和多选批量整理；附件本体仍建议放在共享文件夹或云盘里。AI 面板可以填 DeepSeek 的 API 地址、Key 和模型，用来生成思维导图、学习建议和复盘提纲。若你是直接双击打开 HTML，个别浏览器可能会拦截接口请求，这时改用本地静态服务器或 WebView 壳更稳。后续可继续升级为自动云端同步或原生 APK。
