# 822 控制工程基础 · 资料目录

与《清华车辆822考研计划》08页题型矩阵对齐的复习资料归档目录。

## 结构建议

```
05_专业课/822控制/
├── 00_教材讲义/         # 控制工程基础教材 + 讲义
├── 01_题型矩阵/         # 08页矩阵：建模/时域/稳定性/根轨迹/频域/校正/状态空间
├── 02_基础题240/        # 240 基础题（阶段1~2使用）
├── 03_芝麻研行专题/      # 2027-03 购买，7月专题强化
├── 04_100题/            # 100 题（真题二轮强化 2027-10）
├── 05_真题/             # 历年真题（开做前扫描一份）
├── 06_大套卷冲刺/        # 冲刺卷（2027-11~12）
└── 07_跨校补题/         # 其他学校相似题型（2027-10后，每周最多1组）
```

## 使用规则（来自计划 08 页）

- 训练材料优先级：教材+讲义 → 240 → 芝麻研行+100题 → 真题/大套卷/冲刺卷
- 跨校补题只补清华相似题型，不偏航（资料膨胀是风险）
- 真题错题要回矩阵模块，只看答案不回课本是最大失分点
